## 내용 수정 방법

### 출강 이력 추가
`assets/data.js` 배열에 항목을 추가합니다.

```js
{"p":"2026.11","y":"2026","o":"기관명","t":"과정명","a":"교육대상","s":false,"c":"public"}
```

- `p` 기간 · `y` 연도 · `o` 기관 · `t` 과정명 · `a` 대상
- `s` 교육지원 여부 (`true` 면 목록에 '교육지원' 배지가 붙고 로고가 흐리게 표시됨)
- `c` 분류: `public`(공공·행정) / `corp`(기업) / `edu`(대학·학교) / `org`(협회·센터)

**이력을 추가하면 `index.html` 의 누적 수치도 함께 고쳐야 합니다.**
해당 위치는 `사이트_수정하기.md` 에 정리해 두었습니다.
현재 수치: **88건 · 84개 기관 · 단독 54 · 교육지원 34**

### 수강생 후기 추가
`index.html` 아래쪽 스크립트의 `REVIEWS` 배열에 넣습니다. 비어 있으면 섹션이 숨겨집니다.
`**강조할 구간**` 으로 감싸면 형광펜 표시가 적용됩니다.

```js
var REVIEWS = [
  { text: "실습 위주라 **배운 걸 바로 업무에 써봤습니다.**", who: "○○구청 직원" }
];
```

### 그 밖의 내용
강의 프로그램·FAQ·경력·자격·문의처는 `index.html` 안의 해당 섹션을 직접 수정합니다.
